# Temporal, spatial, and narrative relations

Classify relations before constructing a story. More than one relation may operate at the same cut.

## Shot-to-shot relations

| Relation | Operational test | Typical evidence |
|---|---|---|
| `physical_continuity` | Could action and space continue without contradiction? | compatible action phase, direction, lighting, geometry, object position |
| `temporal_ellipsis` | Is this the same causal episode after omitted time? | stable goal or location with a changed state |
| `scene_change` | Has physical location or situation changed? | establishing cues, costume, lighting, sound environment |
| `flashback` | Is the later shot an earlier event recalled now? | trigger, altered treatment, known outcome, return signal |
| `flashforward_or_anticipation` | Is it an imagined or actual future possibility? | later fulfillment, conditional framing, predictive insert |
| `parallel_action` | Are separate events made simultaneous or analogous? | alternating spaces, shared deadline/audio, matched actions |
| `viewpoint_switch` | Is one event re-presented through another subject's access? | eyeline, knowledge change, reverse perspective, subjective sound |
| `memory_repetition` | Is a prior image recalled or re-evaluated? | same source image with changed crop, color, text, or context |
| `subjective_fantasy` | Does the image follow desire, fear, or metaphor? | impossible geometry, condensation, overexposure, symbolic substitution |
| `dream_or_threshold` | Does it enter or leave altered consciousness? | bookend, dissolve, silence, floating or enclosed space |
| `screen_mediation` | Is the image seen through a device or framed medium? | REC/HUD, phone, panel, monitor, viewfinder cues |
| `graphic_match` | Is continuity based on form rather than event? | shape, line, color, scale, vector, or composition match |
| `eyeline_match` | Does the next shot answer a look? | gaze direction plus plausible target framing |
| `action_match` | Does an action phase bridge the cut? | compatible pose, vector, and temporal phase |
| `reaction_link` | Does the later shot register the prior event's effect? | expression, gesture, retreat, approach, silence, typography, sound change |
| `causal_consequence` | Does a changed state require the prior event? | object, relationship, goal, or environment has a traceable new condition |
| `sound_bridge` | Does audio join discontinuous images? | continuous voice, phrase, effect, ambience, or rhythm |
| `symbolic_association` | Does adjacency make an abstract proposition? | eye→camera, hand→blood, medicine→diagnosis |
| `contrast` | Is meaning produced by opposition? | warm/cold, full/empty, together/apart, clean/contaminated |
| `deliberate_gap` | Is a missing link itself meaningful? | withheld reaction, abrupt silence, unexplained absence later resolved |
| `uncertain` | Do several relations remain plausible? | missing anchors or contradictory evidence |

## Event-response-state chains

Use the smallest meaningful causal unit:

`event -> response -> state change -> consequence`

- **Event**: something changes or becomes known.
- **Response**: a person, relationship, space, sound, text, or motif registers it.
- **State change**: desire, knowledge, affiliation, agency, danger, or emotional orientation changes.
- **Consequence**: the new state constrains the next event.

The response may be delayed, displaced onto another image, or withheld. Never invent a psychological response solely to make the story smooth.

## Narrative topology

- `single_thread_transformation`: one subject's contradiction changes across the work.
- `dual_thread_relation`: interaction changes one or both subjects; the relation is the main unit.
- `multi_thread_convergence`: separate lines develop and meet at common musical or thematic nodes.
- `episodic_accumulation`: variations accumulate a proposition without strong causal continuity.
- `fragmented_association`: meaning emerges from motifs and contrast more than reconstructed plot.
- `hybrid`: specify which topology dominates each chapter.

For multi-thread works, track when lines alternate, echo, cross, or finally share a frame, phrase, object, or consequence.

## Six clocks

Maintain these independently:

- **playback time**: media timestamp;
- **shot time**: duration and internal progression of the shot;
- **story time**: reconstructed event chronology;
- **subjective time**: memory, fantasy, anticipation, dream, repetition;
- **music time**: beat, phrase, section, build, release;
- **viewer-disclosure time**: when this edit permits the viewer to know something.

Viewer-disclosure time may deliberately delay information that is chronologically earlier.

## Continuity and reaction checks

For physical continuity, compare identity, body/action phase, screen direction, gaze, lighting, geometry, costume, object position, audio, and causal plausibility. Two substantial contradictions should trigger an alternative relation.

For flashback, fantasy, or anticipation, identify trigger, boundary, internal logic, and return signal. If absent, keep the classification tentative.

For a reaction link, ask:

1. What prior event is being registered?
2. Whose state changes?
3. Is the response visible, audible, symbolic, or omitted?
4. Does a later event confirm the change?
5. Could the shot instead be a generic mood image?
