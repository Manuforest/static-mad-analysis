# Temporal and spatial relations

Classify relations between shots before constructing story chronology. Multiple relations may coexist.

| Relation | Operational test | Typical evidence |
|---|---|---|
| physical_continuity | Could the action and space continue without contradiction? | matched pose, direction, lighting, background, action phase |
| temporal_ellipsis | Same causal episode with omitted time? | stable goal/location with changed state |
| scene_change | New physical location or situation? | establishing cues, lighting, costume, sound environment |
| flashback | Does the later shot represent an earlier event? | repeated image, memory trigger, altered grade, known outcome |
| flashforward | Is it an anticipation rather than present action? | later fulfillment, predictive insert, conditional framing |
| parallel_action | Are separate events cross-cut as simultaneous or analogous? | alternating spaces, shared audio deadline, matched actions |
| viewpoint_switch | Is one event re-presented from another subject's access? | eyeline, knowledge change, reverse angle, subjective sound |
| memory_repetition | Is an earlier image recalled or reinterpreted? | near-duplicate source with changed crop/color/context |
| subjective_fantasy | Does the space follow desire/fear rather than physical continuity? | impossible geometry, overexposure, symbolic condensation |
| dream_or_threshold | Does an image mark entry to or exit from altered consciousness? | bookending recurrence, dissolve, silence, floating space |
| screen_mediation | Is the image seen through a TV, phone, camera, panel, or interface? | frame-within-frame, REC/HUD, pixel/display cues |
| graphic_match | Is continuity based on form rather than event? | shared shape, line, color, movement vector, composition |
| eyeline_match | Does the next shot answer a character's look? | gaze direction plus plausible target framing |
| action_match | Does an action bridge the cut? | compatible action phase and screen direction |
| sound_bridge | Does audio establish continuity across discontinuous images? | uninterrupted phrase, effect, voice, or rhythmic pattern |
| symbolic_association | Does adjacency create an abstract proposition? | eye→camera, hand→blood, medicine→diagnosis |
| contrast | Is meaning produced through opposition? | warm/cold, full/empty, together/apart, clean/contaminated |
| uncertain | Do competing relations remain plausible? | missing anchors or contradictory evidence |

## Five clocks

Maintain these independently:

- playback time: timestamp in the media;
- shot time: duration and internal progression of a shot;
- story time: reconstructed chronological event order;
- subjective time: memory, fantasy, dream, anticipation, repetition;
- music time: beat, phrase, section, build, release.

Never use one clock as automatic evidence for another.

## Continuity checklist

For a claimed physical continuation, check subject identity, body/action phase, screen direction, gaze, lighting, background geometry, costume/accessory, object position, audio continuity, and causal plausibility. Two or more contradictions should trigger an alternative relation.

For a claimed flashback or fantasy, identify the trigger, the visual/audio boundary, the internal logic, and the return signal. If these are absent, label the relation tentative.
