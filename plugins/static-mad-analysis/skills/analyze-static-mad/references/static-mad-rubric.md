# Static-MAD critique rubric

Use only when critique or scoring is requested. Analysis of meaning precedes judgment.

| Dimension | Questions |
|---|---|
| Material preparation | Are crops, redraws, restoration, edges, resolution, and texture consistent? |
| Still-image animation | Do parallax, camera, easing, internal motion, focus, and light create intentional space? |
| Composition/typography | Are hierarchy, negative space, screen direction, text legibility, and motif placement controlled? |
| Compositing/transitions | Does each effect connect meaning, motion, form, or music rather than merely increase activity? |
| Color/light/texture | Do visual systems remain coherent and change for interpretable reasons? |
| Audio-visual rhythm | Are beats, phrases, energy, lyrics, holds, and counterpoint differentiated? |
| Narrative/emotion | Can viewers reconstruct changing relationships and stakes without unsupported source knowledge? |
| Style/voice | Does the work develop its own visual language and maintain it across sections? |
| Technical finish | Check encoding, jitter, halos, clipping, illegible text, repeated flashes, and viewing comfort. |

Do not score from isolated showcase frames. Explain deductions with timestamps. Distinguish visual-change density from semantic density.
